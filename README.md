# Plugin Reviewer

Plugin Reviewer is a read-only WordPress admin report for investigating a site's plugin stack. It inventories all plugin types, adds WordPress.org maintenance evidence, explains an abandonment concern score, and measures autoloaded options with conservative candidate-orphan attribution.

The tool gathers evidence; a human makes the verdict. It contains no deactivate, delete, cleanup, or fix controls.

## Requirements

- WordPress 6.0 or newer
- PHP 7.4 or newer

## Install

Download or clone this repository into `wp-content/plugins/plugin-reviewer`, activate it, then open **Tools → Plugin Reviewer**.
